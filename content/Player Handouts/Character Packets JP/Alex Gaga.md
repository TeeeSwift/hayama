# Alex Gaga

この資料は、セッション中に「何ができるか」を思い出すための早見表です。数字で迷ったらキャラクターシートを優先してください。

## まず覚えること

- **クラス:** バード
- **背景:** 隠者
- **最大HP:** 10
- **呪文能力値:** 魅力
- **呪文セーヴ難易度:** 13
- **呪文攻撃ボーナス:** +5
- **呪文スロット:** 1レベル呪文スロット2つ
- **得意なセーヴ:** 敏捷力、魅力
- **大事な感覚:** 観察、違和感、声や表現で場を動かすこと

## ターンの基本

自分のターンでは、だいたい次のものを1回ずつ使えます。

- **アクション:** 攻撃、呪文、Dash、Disengage、Dodge、Help、Hide、Search、Use an Objectなど。
- **ボーナスアクション:** Bardic Inspiration、Healing Wordなど。「Bonus Action」と書かれている時だけ使えます。
- **移動:** 移動速度ぶん動けます。少し動く、行動する、また動く、という分け方もできます。
- **リアクション:** 条件が起きた時に使う反応です。自分のターン外に使うことが多く、通常1ラウンドに1回です。

ボーナスアクションを使う選択肢が複数ある時は、ふつう1つだけ選びます。

よく使うアクション:

- **Dash:** このターンの移動量を追加でもう1回ぶん増やします。
- **Disengage:** このターン、移動しても機会攻撃を受けません。
- **Dodge:** 次の自分のターン開始まで防御に集中します。見えている敵からの攻撃が当たりにくくなり、敏捷セーヴも有利になります。
- **Help:** 味方を助けます。状況が合えば、味方の次の能力値判定や攻撃を有利にできます。
- **Hide:** 隠れます。通常は敏捷力〈隠密〉を振ります。
- **Search:** 探す、見抜く、観察する行動です。通常は判断力〈知覚〉や知力〈捜査〉を使います。
- **Use an Object:** 扉、レバー、道具、薬、重要な小物などを使います。

## ロールの基本

**習熟ボーナス（PB）** は「訓練を受けている」「扱いに慣れている」ことを表します。1レベルのPBは通常+2です。技能、セーヴ、武器、道具、呪文攻撃や呪文セーヴDCなどで、自分が習熟しているものにだけ足します。同じロールにPBを何度も足すことはありません。

- **攻撃ロール:** d20 + 攻撃ボーナスを振り、相手のAC以上なら命中します。
- **呪文攻撃ロール:** 「spell attack」と書かれた呪文では、d20 + 呪文攻撃ボーナスを振ります。
- **セーヴィング・スロー:** 危険を避けたり耐えたりする防御ロールです。DMが指定したセーヴ欄のボーナスをd20に足します。
- **呪文セーヴDC:** 相手がセーヴする呪文では、術者はロールしません。相手がAlexの呪文セーヴDC以上を目指してセーヴします。

## バードとしての動き方

あなたは「味方の成功を押し上げ、敵の大事な行動を崩す」タイプです。

- 味方が重要な判定をしそうなら、Bardic Inspirationを渡す。
- 敵を止めたい時は、Bane、Dissonant Whispers、Sleepを考える。
- 誰かが倒れそうなら、Healing Wordで遠くから助ける。
- 戦闘以外では、会話、観察、演出、幻術で状況を変える。
- 呪文スロットは2つだけなので、「ここが流れを変える場面か」を考えて使う。

## クラス特徴

### Bardic Inspiration

ボーナスアクションで味方にd6のインスピレーションを渡します。味方はあとで重要なd20判定に足して、失敗を成功に変えられるかもしれません。

使いどころ:

- 危ないセーヴ
- 重要な攻撃
- 説得、調査、隠密、脱出などの勝負どころ

### 呪文

キャントリップは何度でも使えます。1レベル呪文はスロットを消費します。

集中が必要な呪文は同時に1つだけ維持できます。ダメージを受けると、集中を保つための耐久力セーヴが必要になることがあります。

## 選んだ呪文

| 呪文               | 種類           | 使う場面                             | 注意                                           |
| ------------------ | -------------- | ------------------------------------ | ---------------------------------------------- |
| Message            | キャントリップ | 離れた相手に小声で連絡したい時       | 隠密、相談、合図に強い                         |
| Minor Illusion     | キャントリップ | 音や小さな幻を作って注意をそらす時   | ダメージはない。発想で強くなる                 |
| Bane               | 1レベル        | 複数の敵の攻撃やセーヴを弱くしたい時 | 集中。敵は魅力セーヴ                           |
| Dissonant Whispers | 1レベル        | 1体を怖がらせ、位置を崩したい時      | 敵は判断力セーヴ。成功でも効果が減る           |
| Healing Word       | 1レベル        | 遠くの味方を回復したい時             | ボーナスアクション。倒れた味方を起こすのに便利 |
| Sleep              | 1レベル        | 弱った敵や弱い敵をまとめて止めたい時 | 集中。強い敵には効きにくいことがある           |

## 戦闘で迷ったら

1. 誰かが重要な判定をしそうならBardic Inspiration。
2. 敵をまとめて弱らせたいならBane。
3. 味方が危ないならHealing Word。
4. スロットを温存したいならMinor Illusionや通常行動で場を作る。

## 背景メモ

Alexは地質と環境のコンサルタントとして、建設や開発の安全性、災害対策、環境リスクを評価してきました。

彼女は構造、根拠、調査を大切にする人ですが、いまは科学の言葉だけでは届かないものを、歌やパフォーマンスで表そうとしています。

今の住まいは、地元の音楽ライブやアートイベントを開くレストランの上にあるアパートです。生活の下の階からは、演奏、会話、料理の匂い、町の人たちのざわめきが上がってきます。芸術家としての道はまだ安定しておらず、仕事として成立させる難しさを日々感じています。

## 最近の出来事

レストランと建物のオーナーであるBeatriceは、ゆっくりした話し方の、夢見がちな、控えめなおばあさんです。Alexのアートをいつも辛抱強く応援してくれます。

その時の言葉は、Alexの中に残っています。「芸術家の責任は、人々に『彼ら対私たち』の中に『彼ら』なんていないと気づかせることだよ。」

仕事の面では、AlexはVincentと何度か一緒に動いたことがあります。市の案件、公共・民間プロジェクト、改修、新築などでAlexがコンサルタントとして関わり、Vincentはより上の指揮系統から現場や調整を見ていました。深く付き合う間柄ではありませんが、お互いに顔と仕事ぶりを知っていて、会えば礼儀正しく話せる関係です。

## 関係

- **Beatrice:** レストランと建物のオーナー。ゆっくり、夢見がち、控えめで、Alexの芸術を温かく支えてくれる。
- **Vincent:** 複数の地域プロジェクトで接点がある。上の立場から現場を見ているため頻繁には会わないが、互いに認識していて関係は良好。
- **昔からの研究仲間:** 大学時代から研究・職業人生を通じて知る友人。今も科学の世界に深くいて、Alexの芸術への転向にはまだ納得していない。最新研究を読んだか、次の地質学会に参加するのか、とよく聞いてくる。

## 場所・手がかり

- 地元の音楽ライブやアートイベントを開くレストラン
- レストランの上にあるAlexのアパート
- 市や民間の建設・改修プロジェクトの現場
- 芸術活動の収入や評価がまだ安定しない日々

## ロールプレイの軸

- 科学者としての厳密さと、芸術家としての直感の間で揺れている。
- 芸術を仕事にする難しさを感じながらも、表現を諦めたくない。
- 昔の仲間から研究や学会の話を振られるたびに、自分がどこへ向かっているのかを少し考えてしまう。
- Beatriceの言葉は、優しさ、責任、境界を越える表現を思い出させる。
